# سرور و پنل پزشک

این پوشه سرور برنامه است. نتایج آزمون‌ها را از گوشی بیماران می‌گیرد و در پایگاه داده‌ی PostgreSQL نگه می‌دارد. پنل وب پزشک و مدیر هم از همین سرور باز می‌شود.

- **فناوری:** Kotlin با Ktor، پایگاه داده‌ی PostgreSQL 16، و Docker Compose برای نصب.
- **جدایی از اپ:** یک پروژه‌ی Gradle جداست. ساخت اپ اندروید در Android Studio به آن کاری ندارد.

## نقش‌ها

- **مدیر:** حساب پزشکان را می‌سازد، غیرفعال می‌کند یا رمزشان را عوض می‌کند. مدیر به داده‌ی بیماران دسترسی ندارد.
- **پزشک:** با شماره‌ی موبایل و رمز وارد می‌شود.
  - برای هر بیمار یک «کد دعوت» یک‌بارمصرف می‌سازد که ۷ روز اعتبار دارد.
  - فقط بیمارانی را می‌بیند که با کد خودش وصل شده‌اند، با نمودار نمره‌ی عملکرد در حالت ON و OFF و همه‌ی اندازه‌های هر آزمون.
- **بیمار (پنل وب):** در اپ، بخش «اتصال به پزشک»، یک رمز پنل می‌گذارد. سپس در همین سایت با گزینه‌ی «بیمار»، کد ملی و همان رمز وارد می‌شود.
  - نتایج، خلاصه‌ی روند و پیام‌هایی را که پزشک برایش «قابل‌دیدن» کرده می‌بیند.
- **بیمار (گوشی):** در اپ، کد دعوت را وارد می‌کند. سرور یک توکن مخصوص همان بیمار روی همان گوشی می‌دهد و اپ نتایج را با آن می‌فرستد.
  - هر نتیجه یک بار ذخیره می‌شود، حتی اگر دو بار فرستاده شود.

## حریم خصوصی

- کد ملی هیچ‌جا به‌صورت خام ذخیره نمی‌شود. سرور فقط یک هش کلیددار (HMAC با `NATIONAL_ID_PEPPER`) و ۴ رقم آخر را نگه می‌دارد.
- از رمزها و توکن‌ها هم فقط هش نگه داشته می‌شود (BCrypt و SHA-256).
- هر بار که پزشک پرونده یا نتایج یک بیمار را باز کند، در جدول `access_log` ثبت می‌شود.
- اگر پزشک بیمار پزشک دیگری را بخواهد، جواب «پیدا نشد» می‌گیرد.
- ورود و اتصال گوشی به ۱۰ بار در دقیقه برای هر نشانی محدود است.

## نصب روی سرور

به یک سرور لینوکس با Docker و یک دامنه نیاز دارید که به آن سرور اشاره کند.

```bash
git clone https://github.com/abdollah1366/parkinson.git
cd parkinson/server
cp .env.example .env
# .env را باز کنید و همه‌ی مقدارها را پر کنید. برای رمزهای تصادفی:
openssl rand -base64 48
docker compose up -d --build
```

Caddy گواهی HTTPS را خودش می‌گیرد. بعد از اجرا:

1. نشانی `https://دامنه‌ی-شما` را باز کنید.
2. با `ADMIN_MOBILE` و `ADMIN_PASSWORD` وارد شوید و پزشکان را اضافه کنید.

مقدار `NATIONAL_ID_PEPPER` را هرگز عوض نکنید. اگر عوض شود، بیمارانی که قبلاً ثبت شده‌اند برای سرور ناشناس می‌شوند.

## آزمایش روی کامپیوتر خودتان (ویندوز)

برای آزمایش، سرور می‌تواند روی همان کامپیوتری اجرا شود که با آن کار می‌کنید. گوشی و کامپیوتر باید به یک Wi‑Fi وصل باشند. XAMPP لازم نیست؛ این سرور از Apache، PHP و MySQL آن استفاده نمی‌کند و کنار آن بی‌مشکل اجرا می‌شود.

1. **Java 21** را نصب کنید (مثلاً Temurin 21 از adoptium.net).
2. **PostgreSQL 16** را نصب کنید (از postgresql.org، بخش Windows). رمزی را که هنگام نصب برای کاربر `postgres` می‌گذارید یادداشت کنید.
3. پوشه‌ی `server` را باز کنید و روی `run-local.bat` دو بار کلیک کنید.
   - رمز PostgreSQL را می‌پرسد.
   - بار اول چند دقیقه طول می‌کشد، چون کتابخانه‌ها را دانلود می‌کند.
   - پایگاه داده‌ی `parkinson` خودکار ساخته می‌شود.
   - اگر ویندوز درباره‌ی دیوار آتش (Firewall) پرسید، اجازه‌ی **شبکه‌ی خصوصی (Private)** را بدهید.
4. **پنل:** در مرورگر کامپیوتر `http://localhost:8090` را باز کنید. با مدیر (`09120000000` و رمز `admin12345`) وارد شوید و یک پزشک بسازید. سپس با حساب پزشک وارد شوید و کد دعوت بسازید.
5. **نشانی کامپیوتر:** پنجره‌ی سیاه، نشانی کامپیوتر در Wi‑Fi را نشان می‌دهد (خط IPv4، مثلاً `192.168.1.5`).
6. **گوشی:** در اپ، «اتصال به پزشک» را بزنید. نشانی سرور را `http://192.168.1.5:8090` بنویسید (با نشانی کامپیوتر خودتان) و کد دعوت را وارد کنید.

`http://` فقط در نسخه‌ی آزمایشی (Debug) اپ و فقط برای نشانی‌های شبکه‌ی داخلی پذیرفته می‌شود. نسخه‌ی نهایی فقط به HTTPS وصل می‌شود. رمزهای داخل `run-local.bat` فقط برای آزمایش است و داده‌ی واقعی بیماران نباید روی آن بماند.

## پشتیبان‌گیری

```bash
docker compose exec db pg_dump -U parkinson parkinson | gzip > backup-$(date +%F).sql.gz
```

## توسعه و تست

- تست‌ها به یک PostgreSQL نیاز دارند.
- اگر `TEST_DATABASE_URL` خالی باشد، Testcontainers خودش یک PostgreSQL در Docker بالا می‌آورد.

```bash
./gradlew test
# یا با یک PostgreSQL موجود:
TEST_DATABASE_URL=jdbc:postgresql://127.0.0.1:5432/parkinson_test TEST_DATABASE_USER=postgres ./gradlew test
```

## API

| مسیر | چه کسی | کار |
|---|---|---|
| `POST /api/auth/login` | پزشک و مدیر | ورود با موبایل و رمز؛ توکن ۱۲ ساعته |
| `GET /api/me` و `POST /api/me/password` | پزشک و مدیر | حساب خود و تغییر رمز |
| `GET`, `POST /api/admin/doctors` و `PATCH /api/admin/doctors/{id}` | مدیر | فهرست، افزودن، فعال‌کردن و غیرفعال‌کردن، رمز تازه |
| `GET`, `POST /api/doctor/invites` | پزشک | کدهای دعوت |
| `GET /api/doctor/patients` | پزشک | بیماران خود |
| `GET /api/doctor/patients/{id}` و `GET /api/doctor/patients/{id}/results?type=` | پزشک | پرونده و نتایج یک بیمار (ثبت در `access_log`) |
| `POST /api/device/link` | گوشی | اتصال با کد دعوت؛ پاسخ آن `patientToken` است |
| `POST /api/device/results` | گوشی (توکن) | فرستادن نتایج؛ فرستادن دوباره بی‌خطر است |
| `PUT /api/device/profile` | گوشی (توکن) | به‌روزکردن مشخصات (کد ملی تغییر نمی‌کند) |
| `GET /api/device/status` و `DELETE /api/device/token` | گوشی (توکن) | وضعیت و قطع اتصال |
| `GET /api/doctor/patients/{id}/analysis` | پزشک | خلاصه‌ی روند هر آزمون: ابتدا و اخیر، ON و OFF، شیب ۳۰ روزه |
| `GET`, `POST /api/doctor/patients/{id}/notes` و `DELETE /api/doctor/notes/{id}` | پزشک | یادداشت‌های خود پزشک؛ با `sharedWithPatient` بیمار هم می‌بیند |
| `GET /api/doctor/patients/{id}/results.csv` | پزشک | خروجی CSV برای Excel و نرم‌افزار آماری |
| `POST /api/auth/patient-login` | بیمار | ورود با کد ملی و رمز پنل |
| `GET /api/patient/me`، `results`، `analysis`، `notes` و `POST /api/patient/password` | بیمار | پنل خود بیمار |
| `PUT /api/device/web-password` | گوشی (توکن) | گذاشتن رمز پنل بیمار |
| `GET /health` | همه | سلامت سرور و پایگاه داده |
